# Design inspiration sources for Jeriko

Use these as taste/reference sources, not as automatic code sources.

## Mobbin — https://mobbin.com
Best for product UX, SaaS dashboards, onboarding, settings, empty states, mobile flows, forms, filters, and real app interaction patterns. Use when building full-stack apps.

## 21st.dev — https://21st.dev
Best for modern React component ideas. Good for cards, nav, hero effects, dashboards, command palettes, and interaction patterns. Verify dependencies and licenses before adapting any component.

## Design Spells — https://designspells.com
Best for micro-interactions and delightful details: hover states, pointer effects, playful motion, transitions, easter eggs. Use sparingly; contractor/local-service sites should stay trustworthy and fast.

## Godly.website — https://godly.website
Best for premium landing-page composition: hero layout, typography, spacing, dark-mode polish, high-end section sequencing, visual drama.

## DesignVault / ScreensDesign — https://designvault.io redirects to https://screensdesign.com
Best for mobile app screens, onboarding, paywalls, subscription UX, and product screen references.

## Guardrails

- Inspiration is not permission to copy.
- Prefer project-native React + Tailwind + Radix + Framer Motion.
- Keep accessibility and performance ahead of visual gimmicks.
- For local-service/contractor sites, avoid SaaS-style language unless the business actually sells software.
- For full-stack apps, copy UX patterns such as empty states, table actions, filters, validation, onboarding, and settings structure.
